Помощь по использованию

Назначение вкладок

  • Загрузка — загрузка .csv/.txt/.xlsx файлов с оценками. Файл должен содержать столбцы: Group, LastName, FirstName, Patronymic, и предметы.
  • Редактирование — добавление, редактирование и удаление записей об учениках.
  • Статистика — табличная статистика: средний балл, медиана, распределение оценок.
  • Графики — визуализация статистики в виде диаграмм.

Формат файла

Пример CSV файла:

Group,LastName,FirstName,Patronymic,ИВТС,ЦОС,ИТ,ТЭС,КПК,Философия,Криптография,Антенны,Физра
3 курс,Иванов,Иван,Иванович,5,4,5,5,4,5,4,5,5
3 курс,Петров,Пётр,Петрович,4,5,4,4,5,4,5,4,5
